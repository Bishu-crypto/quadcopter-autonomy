# Developer Tools & Utilities

This directory contains standalone tools, data parsers, and custom developer applications for the Voyager project.

---

## Purpose

We store developer utilities here that are not part of production modules:
- Flight log parsers (e.g., converting `.ulg` or custom binary telemetry streams to CSV).
- Sensor calibration helper tools (ellipsoid fitting plots, least-squares calculators).
- Telemetry packet injectors (for testing link failures or safety overrides).
- MATLAB or Python plotting scripts for control loop response analysis.
