# Static Assets

This directory stores non-code assets, documents, and media for the Voyager UAV ecosystem.

---

## Structure

- **`images/`**: Diagrams, screenshots, and visual documentation assets.
- **`reports/`**: Academic papers, project reports, and PDF presentation materials.
- **`models/`**: (Future) 3D CAD files, STL models for 3D printing, and URDF/SDF description files.
- **`hardware/`**: (Future) Schematic PDFs and electrical wiring guides.
